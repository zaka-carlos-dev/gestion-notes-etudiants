# Gestion Notes Étudiants - V2 Pro 🎓

Application web pour calculer automatiquement les moyennes des étudiants BTS.

**🔗 Site en ligne:** https://gestion-notes-etudiants-lr2g.onrender.com

### 🚀 Nouveautés V2 (ce qui change de la V1)
- ✅ **Moyenne Générale auto** : `Maths + Français + Anglais / 3 = 12.0/20`
- ✅ **Mention auto** : Passable, Assez Bien, Bien, Très Bien
- ✅ **Rang** : 2ème sur 24 élèves (classement auto)
- ✅ **Statut** : Admis / Redouble
- ✅ **Dashboard Pro** : Total étudiants, Taux admission, Moyenne classe, Meilleure moyenne
- ✅ **Design pro** avec cartes colorées

### Avant vs Après
- **Avant V1:** `Nom / Matière / Note` - juste une liste
- **Après V2:** Tableau complet qui évite les calculs à la main

### Stack
Python - Flask - Flask-SQLAlchemy - SQLite - Bootstrap 5 - Render
